# Star patrol

A small browser space shooter in a single HTML file. No build step and no dependencies, so it runs anywhere that serves static files.

Play it at: https://YOUR-USERNAME.github.io/star-patrol/

## How to play

Move with the arrow keys or WASD, hold Space to fire, and press P to pause. On a phone or tablet, drag on the game to steer; firing is automatic.

Destroyed enemies sometimes drop power-ups: a purple 3 for triple shot, a blue S for a one-hit shield, and a red + for an extra life. Your best score is saved in your browser.

## Deploying to GitHub Pages

1. Put `index.html` in the root of a public repository.
2. Go to Settings, then Pages.
3. Under "Build and deployment", set Source to "Deploy from a branch", pick `main` and `/ (root)`, and save.
4. After a minute or two the game is live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.
